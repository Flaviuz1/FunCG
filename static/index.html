Basics

Operators
  • + - * / standard arithmetic
  • ^ exponentiation — right-associative: 2^2^3 = 2^(2^3)
  • -2^2 = −4 (unary minus has lower precedence than ^)
Constants
  • pi — π ≈ 3.14159265
  • e — Euler's number ≈ 2.71828182
  • inf — ∞, usable as an integral bound
Writing rules
  • Function names must be lowercase
  • Use () for grouping
  • All trig inputs are in radians
  • Use x as the variable in Graph mode

Functions

Trigonometry
  • sin(x), cos(x), tan(x), ctg(x)
  • arcsin(x), arccos(x)
  • arctg(x) or arctan(x)
  • arcctg(x)
Logarithm & roots
  • logarithm(x) — natural log ln(x)
  • logarithm(b, x) — log base b of x
  • root(n, x) — nth root of x
  • abs(x) or absolute(x)
Rounding & misc
  • floor(x) — round down
  • ceiling(x) — round up
  • factorial(n) — n!
  • mod(a, b) — remainder
Combinatorics
  • combinations(n, k) — C(n,k)
  • arrangements(n, k) — P(n,k)
  • permutations(n) — n!
  • gcd(a, b), lcm(a, b)
Statistics
  • mean(a, b, c, ...)
  • variance(a, b, c, ...)
  • stdev(a, b, c, ...)

Calculus

Summation Σ
  • sum(var, lower, upper, expr)
  • Example: sum(k, 1, 100, 1/k^2)
Product Π
  • product(var, lower, upper, expr)
  • Example: product(k, 1, 5, k) → 120
Integral ∫
  • integral(var, lower, upper, expr)
  • Example: integral(x, 0, pi, sin(x))
  • Supports inf and -inf as bounds
Limits
  • lim(var, to, expr)
  • Example: lim(x, 0, sin(x)/x)
  • One-sided limits handled automatically
Note: Integrals use composite 5-point Gauss-Legendre quadrature — much more accurate than standard trapezoid methods. Infinite bounds are supported natively via inf / -inf.

Graph Mode

How to use
  • Switch to the Graph tab
  • Enter any expression using x as the variable
  • Adjust X / Y bounds with the controls that appear
  • Press Run or hit Enter
Example expressions
  • sin(x) / x
  • e^(-x^2)
  • x^2 * sin(1/x)
  • tan(x)
  • logarithm(e, x)
Tips
  • Asymptotes (e.g. in tan) are detected and not drawn through
  • For flat curves like e^(-x^2), narrow the Y range (e.g. −0.2 to 1.2)
  • Resizing the window redraws automatically
